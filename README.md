# Mi Proyecto
## Qué es GitHub
GitHub es una plataforma fundada en 2008 por Tom Preston-Werner, Chris Wanstrath, P. J. Hyett y Scott Chacon, que sirve para compilar software, permite a los desarrolladores crear, almacenar, administrar y compartir su código. GitHub ofrece todo lo necesario para el desarrollo de software, tanto si inicias un nuevo proyecto como si contribuyes a uno ya existente.
